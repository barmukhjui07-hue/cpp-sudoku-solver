🧩9x9 Interactive Sudoku Game (C++)
A beginner-friendly terminal-based Sudoku game built using C++.
🚀 Features:
- Interactive 9x9 Sudoku board.
- Instant input validation (Row 0-8, Column 0-8, Number 1-9).
- Press `-1` anytime to exit and reveal the complete solved grid.
- 
🛠️ How to Run:
1. Open your terminal in the project folder.
2. Compile: `g++ main.cpp -o Sudoku.`
3. Run: `.\Sudoku`
